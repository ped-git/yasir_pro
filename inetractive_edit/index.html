A quick guide to editing

  1. Choose a workspaceUse the top-bar selector to edit interactive or interactive_beta. Unsaved changes must be confirmed before switching.
  2. Select the passageDrag across text in the page. Right-click for the quick menu, or choose a category and style from the sidebar.
  3. Build underline layersChoose Underlines, set the line type, distance, color, and thickness, and check the preview before applying. Select text inside an underline to create a nested layer. Select a layer and use the eraser to remove only that layer.
  4. Manage groupsCheck underlines in the list or Command/Ctrl-click them in the page. Replace, add, or remove specific group memberships, or ungroup the selection. Choose a group above to select its current members.
  5. Add quotation marksSelect the quoted text, choose a speaker color, and select Pair selection. To recolor or remove a pair, select either mark in the page first.
  6. Draw vertical sectionsSelect text or paragraphs, choose Vertical sections and a line style. Select inside a section to nest another. The eraser removes only the selected section and its own ornaments.
  7. Save safelyUndo and redo unsaved steps. Save writes a backup and checks that text and whitespace have not changed.
